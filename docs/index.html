GETTING STARTED

From clone to first graph.

These commands use the filenames currently present in your GitHub repository. Python 3.11 or 3.12 is recommended; a GPU is not required for the orchestration examples.

Install dependencies
git clone https://github.com/su394611-del/Mutli-agents-using-LangGraph.git
cd Mutli-agents-using-LangGraph
py -3.12 -m venv .venv-langgraph
.\.venv-langgraph\Scripts\python.exe -m pip install --upgrade pip
.\.venv-langgraph\Scripts\python.exe -m pip install -r requirements_langgraph_example.txt
List and self-test examples
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --list
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --self-test
Run a selected workflow
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --topic conditional_edges
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --topic subgraph_wrapper
Export graph source and results
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --export-mermaid .\diagrams --json-output .\results.json

API-free first

Use --self-test to run and validate the sixteen offline examples. No OpenAI key or model download is needed.

Optional LLM integration

Only run --with-llm, --topic llm_node, or --topic messages_state_llm after configuring an OpenAI API key. Hosted calls can incur charges; never commit keys.

Run optional LLM example
$env:OPENAI_API_KEY = Read-Host "OpenAI API key"
.\.venv-langgraph\Scripts\python.exe langgraph_example_multi_agents.py --topic llm_node

Jupyter or VS Code

The companion notebook is langgraph_exmaple_multiagents.ipynb. Select an environment with the requirements installed. The notebook supports offline runs by default.

Mermaid export

--export-mermaid produces local .mmd files; it does not require a remote image-rendering service. --json-output writes reproducible example results.

Implementation boundaries

This is a runnable Python learning project for LangGraph orchestration. Its offline examples use deterministic Python operations—not an on-device trained language model.

  • The two OpenAI examples require credentials, network access and optional third-party packages.
  • HR/IT subgraphs model workflow coordination; they do not constitute a deployed multi-agent workforce.
  • No proprietary training data, model weights, distributed training, inference benchmark, or enterprise availability claim is implied.
  • Examples cover graph logic, but production deployments require appropriate persistence, testing, observability, access controls, and failure handling.
