Multi-Agent Workflows Using LangGraph

An educational Python project demonstrating LangGraph workflows, state management, conditional routing and subgraph orchestration.

Project Features

  • LangGraph StateGraph architecture
  • Graph nodes and edges
  • Conditional edges and routing
  • TypedDict state management
  • Pydantic state validation
  • Input and output state schemas
  • Private and intermediate state
  • State reducers and custom reducers
  • add_messages and MessagesState
  • HR and IT subgraph orchestration
  • Optional OpenAI LLM integration
  • Python and Jupyter Notebook examples

Architecture and Design

The project explores LangGraph orchestration, shared graph state, conditional execution, and reusable subgraph patterns.

Execution Modes

Most demonstrations run offline without an LLM API. Selected examples optionally use OpenAI models when configured.
